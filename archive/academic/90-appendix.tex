\begin{frame}{Optional deep cut: world models plus forks, not either/or}
\large
A strong system can use both:
\vspace{0.4em}
\begin{enumerate}
  \item learned model proposes promising branches,
  \item forked executable worlds ground those branches,
  \item reducer compares evidence with lineage,
  \item controller promotes once.
\end{enumerate}
\vspace{0.7em}
\begin{block}{Hybrid thesis}
Use imagination for breadth. Use executable forks for truth.
\end{block}
\end{frame}

\begin{frame}{Optional deep cut: why the title says factory}
\large
A factory is not only parallel compute. It is a controlled path from motion to matter.
\vspace{0.6em}
\begin{columns}[T,onlytextwidth]
\column{0.47\textwidth}
\textbf{Motion}
\begin{itemize}
  \item disposable attempts
  \item agent sessions
  \item rollout trajectories
  \item speculative patches
\end{itemize}
\column{0.47\textwidth}
\textbf{Matter}
\begin{itemize}
  \item accepted source snapshot
  \item evidence ledger
  \item release checkpoint
  \item paper / product claim
\end{itemize}
\end{columns}
\vspace{0.7em}
\centering \large Create entropy where exploration pays; destroy entropy before promotion.
\end{frame}
