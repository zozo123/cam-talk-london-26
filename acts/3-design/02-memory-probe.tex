\qadetail{Gate 0 is preregistered and unrun; the diagram is an experiment design, not a result. Current API measurements establish restore fan-out without verified memory semantics. The original result-description table is: files surviving only support filesystem restore; process and RAM surviving supply evidence of process and memory restoration; matching declared semantic checks support fidelity for those checked properties only. The RAM-only 128-bit nonce is a necessary probe, not a complete fidelity proof. Compare declared deterministic outputs between direct and restored execution, ignoring timestamps only when the protocol declares them irrelevant. Check private writes, process identity, clocks, random state and sockets as relevant. Worktrees, CRIU, VM snapshots and replay logs restore different state. A snapshot name does not establish memory semantics. Hosted-model weights, KV state and sampling are outside the guest. A failed nonce probe requires reporting the actual filesystem/restore semantics. A successful probe still requires useful captured state and declared semantic tests.}
\note{[0:45] This design makes the memory claim testable. A live process creates a hundred twenty-eight bit nonce and holds it only in RAM. Capture the parent, restore three children, and check the process and nonce in every child. The nonce must survive through the memory path. This is a necessary probe, followed by declared behavioral checks for the workload. Gate zero awaits execution. The result will tell us which state-preservation claim our restore path can support, before we time useful continuations.}
