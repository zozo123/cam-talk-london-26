\qadetail{The original state-surface table distinguishes source/build state (Git worktrees, OBuilder), process state (CRIU, gVisor save/restore), VM state (Xen, SnowFlock, Firecracker), and recorded observations (rr, DSec replay). The main slide groups process and VM mechanisms without equating their supported state. Worktrees parallelize edits without preserving live processes. gVisor supplies a userspace-kernel sandbox with its own supported save/restore semantics. Replay can reuse a response without reexecuting a remote service. Network, time, randomness and remote model sessions need declared semantics. The factory case establishes files, dependencies and failed-test feedback, not a necessary live process. An unchanged simulator or application at a reproduced failure is a possible useful live-state workload, not an observed property of the allowlist repair. Editing loaded code may require reload or restart and invalidate the captured live state. Hosted-model weights, KV state and sampling stay outside the guest. Choose the cheapest faithful mechanism for the next action. Q&A extension from acts/3-design/02-memory-probe.tex: Gate 0 is preregistered and unrun; the diagram is an experiment design, not a result. Current API measurements establish restore fan-out without verified memory semantics. The original result-description table is: files surviving only support filesystem restore; process and RAM surviving supply evidence of process and memory restoration; matching declared semantic checks support fidelity for those checked properties only. The RAM-only 128-bit nonce is a necessary probe, not a complete fidelity proof. Compare declared deterministic outputs between direct and restored execution, ignoring timestamps only when the protocol declares them irrelevant. Check private writes, process identity, clocks, random state and sockets as relevant. Worktrees, CRIU, VM snapshots and replay logs restore different state. A snapshot name does not establish memory semantics. Hosted-model weights, KV state and sampling are outside the guest.
