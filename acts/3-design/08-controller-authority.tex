\qadetail{Controller-held publication is exercised; fresh clone authority remains proposed. The original contract table retains immutable parent/cache digest identity and a declared trust domain, private writable child state, host-authenticated and authorized child identity/epoch/expiry/budget, and a controller-held publishing credential whose approval names the artifact. A microVM can contain a still-valid bearer token. Kernel isolation does not make that token harmless. Guest-supplied generation strings are copied and cannot authenticate a clone; fresh identity alone does not confer authority. The host must authenticate and authorize each child separately. VMGenID can reseed the kernel; userspace RNG treatment is application-dependent. Refresh network identity, clock and socket semantics. Immutable caches still need a trust and leakage policy. Egress policy is distinct from withholding publication credentials. Every candidate needs verification of its required behavior and exact digest before a current publication decision.}
\note{[0:45] The child works in private writable state and returns a candidate. The controller holds the publishing credential and binds approval to the artifact. This keeps publication outside the copied guest state. A bearer token inside a snapshot could otherwise remain usable in every child. Each child's permissions also need host authentication and authorization, with scope, expiry and budget. The factory exercised controller-held publication; clone authorization is an extension design.
