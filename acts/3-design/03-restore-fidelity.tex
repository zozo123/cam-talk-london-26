\qadetail{Gate 0 is preregistered and unrun; the diagram is an experiment design, not a result. Current API measurements establish restore fan-out without verified memory semantics. The RAM nonce is a necessary probe, not a complete fidelity proof. Compare declared deterministic outputs between direct and restored execution, ignoring timestamps only when the protocol declares them irrelevant. Check private writes, process identity, clocks, random state and sockets as relevant. Worktrees, CRIU, VM snapshots and replay logs restore different state. A snapshot name does not establish memory semantics. Hosted-model weights, KV state and sampling are outside the guest. A failed nonce probe requires reporting the actual filesystem/restore semantics. A successful probe still requires useful captured state and declared semantic tests.}
\note{[0:55] Here is the restoration experiment. A process generates a hundred twenty-eight bit nonce and holds it only in RAM. Capture that state, restore three children, and check that each child has the live process and the same nonce. Files surviving establishes a filesystem path. The process and nonce surviving adds evidence for the memory path. Then compare the declared deterministic behavior against direct execution, with workload-specific checks for writes, clocks, randomness and sockets. Gate zero is preregistered and awaits execution. It gives us a concrete way to label the state our API actually preserves.}
