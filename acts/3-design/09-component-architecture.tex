The repository is the destination behind the gate; a refusal does not imply publication occurred. No factory case-study run forked. Returned evaluation receipts must name the exact candidate digest. Named-snapshot API paths were exercised separately. The numerical reducer was built separately; a lease broker exists but was unused in these work orders. Calibrated dependence and epoch-fenced publication are proposed. Calls checkpoint, fork, evaluate, select, reduce and promote express different decisions. The eight obligations retained from the prior deck are: identified immutable parent; fresh child authority; no guest publishing token; input/evidence/feedback records; duplicate rejection plus retained shared factors; deterministic composition and conflict retention; exact-composition verification; durable export on every exit. Selection/composition of patches is separate from common-target numerical reduction. An authentic receipt alone cannot establish behavioral coverage or statistical calibration.}
\note{[0:45] The solid path is the exercised serial architecture. Airflow schedules a Docker work cell. The cell returns an artifact digest, and the controller checks artifact-bound approval before repository publication. The journal records those decisions. The dashed fork store and evaluator are designed extensions. They would bring candidate artifacts and identified evaluation receipts back to the same gate. The numerical reducer was built separately for measurement summaries. This architecture gives each component a specific job while keeping the final publication decision with the controller.}
