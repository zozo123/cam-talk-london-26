\note{[0:55] A worker should return a receipt. The receipt contains the result, the evidence it used and its origin. The built part merges summaries in any order and stops when evidence is used twice. We propose that each evidence ID corresponds to one execution. If the runtime cannot determine how much the copies share, it should abstain. A hedged request is a speculative duplicate of an earlier request. DeepSeek's DSec replays cached results instead of re-running them. Such evidence should be counted once. The estimator is Cochran's. The proposed contract specifies how the inputs to that estimator are counted.}
