\qadetail{The existing gate prototype and full integration lifecycle have distinct implementation status. This frame states the proposed end-to-end behavioral obligation, not a newly measured fork deployment. Scope authorization, an executed receipt, behavioral coverage, exact-composition verification, artifact-bound approval and current controller authority are separate obligations. A valid digest proves identity, not correctness. A passing regression path supports that behavior; it does not establish held-out accuracy or ensemble confidence. The gate is proposed; the built digest gate and numerical reducer do not supply all these checks. Durable export prevents the second incident's teardown loss.}
\note{[0:55] The factory recorded nineteen hundred seventy-two passing cases, while the same-owner busy-path test was absent. That missing obligation becomes a publication rule. Freeze the artifact bytes. Outside the child, force the busy path and assert exactly one backend dispatch. Bind the check to those exact bytes, then let the controller publish them once. A pass count cannot substitute for this behavior. Scope, current authority and durable export remain part of acceptance; the numerical reducer cannot supply those checks.}
