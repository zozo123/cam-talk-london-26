\claim{A fixed evaluator turns code generation into a hill-climbing loop.}
\sources{\href{https://github.com/karpathy/autoresearch/blob/master/program.md}{autoresearch protocol}; \href{https://github.com/karpathy/autoresearch/discussions/43}{maintainer's reported session}. Five minutes is the training budget per completed attempt.}
\qadetail{This is one reported session, not a controlled average effect. The score decline is (0.997900-0.969686)/0.997900=2.827\%. The protocol holds prepare.py, data preparation, tokenizer and evaluation fixed and permits editing train.py. Five minutes is wall-clock training time; startup and compilation occur outside that budget, and crashes can end early. Sequential Git keep/revert is the actual mechanism. Forked parallel continuations are a possible implementation extension, not what produced this reported result. Repeated adaptive selection on one validation set warrants a separate held-out check before claiming generalization.}
\note{[1:00] Autoresearch gives us a very simple research loop. The agent edits training code, runs a five-minute training budget, reads validation bits per byte, and keeps or reverts the change. The evaluator stays fixed. In one reported session, 126 experiments produced twenty-three kept changes, 102 discards and one crash. The best score fell from about point nine nine eight to point nine seven zero, a relative reduction of 2.8 percent. This is sequential hill climbing through Git. The useful abstraction is an incumbent, a candidate, a fixed evaluation and a decision.}
