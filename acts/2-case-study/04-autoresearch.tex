\qadetail{This is one reported session, not a controlled average effect. The score decline is (0.997900-0.969686)/0.997900=2.827\%. The protocol holds prepare.py, data preparation, tokenizer and evaluation fixed and permits editing train.py. Five minutes is wall-clock training time; startup and compilation occur outside that budget, and crashes can end early. Sequential Git keep/revert is the actual mechanism. Forked parallel continuations are a possible implementation extension, not what produced this reported result. Repeated adaptive selection on one validation set warrants a separate held-out check before claiming generalization.}

\note{[1:00] Autoresearch edits training code while keeping the evaluator fixed. Each completed attempt receives a five-minute training budget. The agent reads validation bits per byte and keeps or reverts the change in Git. One reported session had 126 attempts: twenty-three kept changes, 102 discards and one crash. The best score fell from point nine nine seven nine to point nine six nine seven, a relative reduction of 2.8 percent. This is sequential hill climbing. A candidate, an executed evaluation and a keep decision make the improvement legible. AlphaEvolve extends this pattern to a population of programs.}
