\note{[0:50] Next is the hedging paper's second technique, for faults in the request. The authors describe a request reaching an untested code path and crashing thousands of servers at once. They propose a canary request sent to one or two leaf servers first. The new code in our first run had no test, so nine passing forks would share that gap. Kohli reports that nine frontier judges who all agreed were still wrong 9.1 percent of the time. We therefore propose a canary for correlation.}
