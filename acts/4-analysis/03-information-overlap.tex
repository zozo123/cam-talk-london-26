\begin{frame}[t]{Combining results should keep shared observations once.\ev{\tagA}}
\begin{center}
\begin{tikzpicture}[x=1cm,y=1cm,every node/.style={align=center,font=\fontsize{12}{15}\selectfont}]

\node[anchor=west,text width=5.5cm,font=\fontsize{11.5}{14}\selectfont]at(3.2,0){\textbf{Union: 4 distinct observations}\\$A\cup B=\{a,b,c,d\}$\\[7pt]\textbf{Intersection: 2 shared observations}\\$A\cap B=\{b,c\}$\\[7pt]\textbf{New from B: 1 observation}\\$B\setminus A=\{d\}$};
\end{tikzpicture}
\end{center}
\tagline{Different observations can still share errors. Mutual information describes statistical dependence.}
\sources{Set diagram: exact illustrative observation IDs. Entropy identity: \href{https://ocw.mit.edu/courses/6-441-information-theory-spring-2016/pages/lecture-notes/}{MIT information-theory notes}.}
\qadetail{The added difference B minus A equals the single new item d. This exact set operation deduplicates declared item identities and does not measure correlation between different items. The statistical entropy identity retained here is H(X,Y)=H(X)+H(Y)-I(X;Y). The circles show overlap of observed-item sets, not areas proportional to Shannon entropy. Cardinality inclusion-exclusion counts each declared observation once. For discrete random variables the joint-entropy identity subtracts their mutual information from the sum of marginal entropies. This is not a prescription to subtract pairwise mutual information from Fisher information or from precision. Entropy of observations differs from information about a parameter. Pairwise dependence need not determine higher-order dependence. Target information can be expressed by the chain rule I(theta;X,Y)=I(theta;X)+I(theta;Y|X), where the second term is the extra information about theta after observing X. The covariance-based example later uses unbiased same-parameter estimates with externally known positive-definite error covariance. Dependence beyond that model needs a justified joint model or conservative uncertainty treatment.}
\note{[0:45] Branch A returns observations a, b and c. Branch B returns b, c and d. Their union contains four distinct observations. Their intersection contains the two shared observations, b and c. B adds only one new item, d, after we have collected A. That is the simplest fan-in rule: retain each shared item once. Different items may still have related errors. Mutual information describes statistical dependence, which needs a model beyond the set labels. Next, choose a return rule that matches the experiment.}
