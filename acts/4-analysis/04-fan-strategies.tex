\begin{frame}[t]{The result type determines the fan-in operator.\ev{\tagP}}
\vspace{0pt}

\tagline{$A_i$: returned items. $V$: candidates that pass checks. $q$: common score. $\Delta_i$: edits from one base.}
\sources{Max pooling returns the highest score. Argmax selects its candidate. ReLU clips negatives: $\operatorname{ReLU}(z)=\max(0,z)$. Agreement can reflect a shared error.}
\qadetail{Operator definitions: A_i is the set of identified items returned by branch i. V is the eligible candidate set after required validity checks; q is one fixed higher-is-better evaluator. Argmax returns a maximizing candidate, while max returns only its score; retain candidate identity and a deterministic tie rule. The named merge function is a partial operation on edits from the same base, with conflict resolution and tests on the resulting whole version. No universal associative or commutative code-merge law is claimed. The weighted mean uses weights that sum to one for same-target estimates. Equal weights give the ordinary average; calibrated covariance determines weights when errors are shared. Preserve counts, identities and the statistical model when combining summaries: an unweighted average of subgroup averages can overweight small groups. Full covariance pooling generally needs the joint error model and is not a blind sum of independent precision weights. Union and intersection are associative, commutative and idempotent on sets of the same declared item IDs. Unique IDs still do not establish statistical independence or truth. ReLU(z)=max(0,z) is a pointwise nonlinear transform, not a reduction across branches. Transforming measurements before averaging can change the target and introduce bias: averaging ReLU(-1) and ReLU(1) yields 0.5, whereas ReLU of their mean is zero. Scalar max pooling returns the largest value; array max pooling can return a componentwise composite that no branch produced, which requires its own validity check. Other task-specific operators include sums for additive disjoint contributions, medians for robust scalar location under an appropriate model, logical AND for all required checks and logical OR for any sufficient passing route. These are alternatives with their own semantics, not additions to a single universal fan-in rule. This is a non-exhaustive menu of common fan-out/fan-in strategies, not a measured implementation. Partitioning disjoint data supports map-and-gather; union alone does not verify completeness or processing correctness. Alternative stochastic proposals support best-candidate selection under a fixed evaluator; coverage is not selected success. Compatible partial changes require semantic integration testing, not only a clean textual merge. Repeated unbiased same-target estimates require covariance/uncertainty accounting; common input IDs do not calibrate that covariance. Intersection shows common findings but correlated checks can agree on the same wrong claim, and legitimate novel findings may appear in only one branch. Disagreement calls for an adjudicating test rather than automatic deletion. Additional strategies retained for Q&A: identical replicas with first-valid selection can reduce tail latency when stragglers have different causes; majority voting needs calibrated errors and can fail under common mistakes; matched trials sharing randomness can improve precision of a difference, while providing fewer independent witnesses for a common mean; hierarchical or beam search can prune failed branches and launch another round from a useful accepted state. Adaptivity makes selection and repeated evaluation part of the measurement protocol. Budgets, timeouts, stopping rules, incomplete returns, current authority and durable output belong to the controller. Choose a rule from output meaning rather than forcing every result through set union. No claim covers every possible parallel algorithm.}
\note{[0:45] Fan-in is a function of the returned outputs. For item sets, union gathers distinct items. For alternatives, argmax returns the candidate with the highest common score among those that pass checks. For compatible code edits, merge constructs a version that must be tested. For repeated estimates of one quantity, use a weighted mean that accounts for shared noise. Intersection returns findings shared by all branches. Max returns a value; argmax returns its candidate. ReLU clips negatives and is a separate transformation.}
\end{frame}
