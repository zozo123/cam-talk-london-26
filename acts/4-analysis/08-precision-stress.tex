\note{[0:50] A weighted average multiplies each estimate by its precision, then divides by total precision. Precision is inverse variance: claiming very little uncertainty gives a worker a very large weight. In our synthetic example, the true value is five. One worker reports a value near seventeen, using two thousand tightly concentrated points and inflating information per point another fiftyfold. It overwhelms unprotected pooling, which returns seventeen point zero zero zero four. The demo's stress heuristic returns four point nine five six six.
