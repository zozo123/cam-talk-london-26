\note{[0:45] Self-driving cars make the feedback idea familiar: observation informs an action, and its effects inform the next action. My work at Mobileye was in perception. A self-driving computer applies a related pattern to software: read the code and execution state, edit and run tools, then use tests and failures to revise the action. The analogy explains the loop. It does not transfer automotive safety guarantees to coding agents. Next, execution reuse gives us a practical starting point.}
