\qadetail{Primary paper: Hitz et al., The ENCODE uniform analysis pipelines, DOI 10.1101/2023.04.04.535623, https://pmc.ncbi.nlm.nih.gov/articles/PMC10371165/. Yossi Eliaz is a coauthor; the slide attributes the infrastructure and throughput to the team. The final-phase pipeline collection processed more than 14,000 datasets, at least 40,000 FASTQ files, across approximately 20 assay types. Dataset counts, input-file counts and assay counts are distinct units. Workflow Description Language specifies workflows; Cromwell executes them; Docker supplies task environments. CAPER handles execution and input/output movement across supported storage and runtime settings. CROO organizes outputs and exposes file tables and connectivity/task graphs. Portal analysis and file objects track pipeline runs, raw source files, software and versions, quality metrics and file relationships. This supports provenance and reproducibility. An output identity or version record does not by itself establish biological correctness, authenticated evidence, or calibrated uncertainty. Do not claim Yossi personally implemented CAPER, CROO or every pipeline without a specific contribution record. Related coauthored portable analysis: Barkai, Malul, Eliaz, Eyal and Veksler-Lublinsky, OffRisk: a docker image for annotating CRISPR off-target sites in the human genome, Bioinformatics Advances 3:vbad138 (2023), DOI 10.1093/bioadv/vbad138, https://pmc.ncbi.nlm.nih.gov/articles/PMC10568243/; official code https://github.com/IsanaVekslerLublinsky/OffRisk. Its two Docker components are a Streamlit UI and Flask server. For a CCR5 guide, CRISPRitz with four allowed mismatches returned 118 sites, including one on-target and 117 off-target. OffRisk annotated genomic and regulatory context and assigned five high-coding labels, including the intended CCR5 target. These labels prioritize sites from annotations, not measured toxicity. Related identity/provenance work: Blackburn, Huber, Eliaz et al., Cooperation among an anonymous group protected Bitcoin during failures of decentralization, arXiv:2206.02871 (2022), https://arxiv.org/abs/2206.02871. Address linking achieved greater than 99 percent sensitivity and specificity, and the reconstruction found 64 agents mined most Bitcoin between 3 January 2009 and 9 February 2011. Distinct address identifiers can name shared underlying actors. The linking performance is not a measurement of fork-induced dependence. The user's confirmed path continues from genomics to Mobileye and self-driving computers; the precise Mobileye responsibilities belong to the user's account and are not inferred from these papers.}
\note{[0:45] At ENCODE scale, we needed executable workflows and a record of what each analysis produced. The uniform pipelines processed more than fourteen thousand datasets. WDL described the workflows, Cromwell ran them, and Docker supplied the task environments. Output records linked back to source files and recorded software versions and quality metrics. That made the analysis traceable beyond one successful run. This is a direct connection to agent execution: a result needs an identity and a record of its production. The environment is one part of that record.}
