\begin{frame}{Execution substrate: six surfaces}
\begin{columns}[T,onlytextwidth]
\column{0.49\textwidth}
\begin{itemize}
  \item \term{Filesystem state}: workspace as a named snapshot
  \item \term{Networking + credentials}: brokered wire, no ambient keys
  \item \term{Reproducibility}: restore by digest, not by hope
\end{itemize}
\column{0.49\textwidth}
\begin{itemize}
  \item \term{Fast cloning}: CoW machine economics, not rebuilds
  \item \term{Build / test / rollout}: warm factory beside trust
  \item \term{Recovery + observability}: receipts outlive machines
\end{itemize}
\end{columns}

\vspace{0.8em}
\begin{block}{Contract}
If any surface is missing, the factory can still run - but it can no longer tell the truth about what happened.
\end{block}

\source{Published Cambridge abstract lists filesystem state, networking/credentials, reproducibility, fast cloning, build/test, recovery, and observability.}
\end{frame}

\begin{frame}{The outer wall still matters}
\Large
Agents with shells are not tenants asking politely. They are programs with search.

\vspace{0.8em}
\begin{columns}[T,onlytextwidth]
\column{0.33\textwidth}
\textbf{Container}\par
\normalsize High density. Good developer ergonomics. Weakest as a hard isolation claim.
\column{0.33\textwidth}
\textbf{User-space kernel}\par
\normalsize Stronger syscall mediation. Still a trade-off between compatibility and boundary.
\column{0.33\textwidth}
\textbf{MicroVM}\par
\normalsize Firecracker-class wall: VM isolation with serverless density.
\end{columns}

\vspace{0.9em}
\begin{block}{Point}
Fork speed is useful only after the escape wall is credible.
\end{block}

\source{Firecracker: Agache et al., NSDI 2020. SandboxEscapeBench: Marchand et al., arXiv:2603.02277.}
\end{frame}

\begin{frame}{Fork becomes an OS primitive}
\begin{columns}[T,onlytextwidth]
\column{0.48\textwidth}
\begin{block}{DeltaBox}
\begin{itemize}
  \item Change-based filesystem + process checkpoint/restore
  \item Complete sandbox state: files, process memory, contexts
  \item Goal: millisecond-level rollback for deep agent search
\end{itemize}
\end{block}

\column{0.48\textwidth}
\begin{block}{Shepherd}
\begin{itemize}
  \item Agent execution as a reversible trace
  \item Fork, replay, and revert as programmable operations
  \item Meta-agent can supervise paths, not just transcripts
\end{itemize}
\end{block}
\end{columns}

\vspace{0.6em}
\centering\Large \hilite{Fork is not a convenience. Fork is the API for search.}
\source{DeltaBox: Dong et al., arXiv:2605.22781. Shepherd: Yu et al., arXiv:2605.10913.}
\end{frame}
