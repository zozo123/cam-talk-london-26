\begin{frame}{Why I ended up working on this}
\begin{columns}[T,onlytextwidth]
\column{0.31\textwidth}
\textbf{1. Computational science}\par
\normalsize I learned that an experiment is not reproducible unless the \emph{machine state}, inputs, and provenance are reproducible too.

\column{0.31\textwidth}
\textbf{2. Production ML + build systems}\par
\normalsize I learned the opposite pressure: reuse everything you safely can --- caches, artifacts, warm state --- because recomputation is expensive.

\column{0.31\textwidth}
\textbf{3. Coding agents}\par
\normalsize Then the developer became a program that runs shells, mutates files, calls networks, retries, and fans out hypotheses.
\end{columns}

\vspace{0.75em}
\begin{block}{The collision}
\centering
\large The thing I wanted to reuse for speed --- \textbf{state} --- became the thing I had to isolate for trust.
\end{block}

\vspace{0.35em}
\centering\large
The missing primitive was not another model. It was a machine state I could \hilite{fork, inspect, revert, and burn} without forking authority.
\end{frame}

% -------------------------------------------------------------------
\begin{frame}{One-sentence talk}
\LARGE
Coding agents, RL post-training, and hardware-in-the-loop all need the same thing:

\vspace{0.7em}
\begin{center}
\begin{minipage}{0.88\textwidth}
\centering
\Huge \hilite{cheap forked machines for search}
\Large \\
\vspace{0.2em}
and a separate authority that never lives inside those machines.
\end{minipage}
\end{center}

\vspace{0.7em}
\large Forkable sandboxes are that machine. Everything else is orchestration.
\end{frame}
