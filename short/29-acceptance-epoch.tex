\claim{Proposed: one controller, current epoch, publish once.}
\sources{Epoch fence and hash-keyed publish: proposed; TLA+ design, no TLC run. Prior art: leases (1989), Chubby sequencers (2006).}
\qadetail{DESIGN scope: the epoch (a permission version number, a fencing token in the Chubby-sequencer sense) is a proposed publication protocol, not an implemented or model-checked result: a TLA+ design exists, with no TLC run or implementation trace check recorded. The controller checks authenticated identity, current epoch, expiry, artifact, scope and budget; evidence, approval and publication must name one frozen artifact. A fence rejects stale results; it does not by itself give exactly-once publication. Publish-once also needs an idempotent publish keyed by the artifact digest, so a controller crash between push and record cannot publish twice; if the controller is ever replicated, the repository itself must check the epoch. Replacement and concurrent fork are distinct: replacing logical worker w invalidates its old epoch, while a concurrent child gets a new worker identity and its own epoch and need not revoke a continuing parent. Fresh identity alone does not confer authority. Authorization is checked outside restored guest state, so a copied local generation value cannot establish current permission. Controller-held publication, with no publish key in the worker, was exercised in the factory runs. A replaced or restored worker may still try to deliver, which is why the fence lives in the controller. Prior art: leases (Gray and Cheriton, SOSP 1989); fencing tokens as in Chubby sequencers (Burrows, OSDI 2006).}
\note{[0:45] So the controller keeps an epoch, a permission version number. Replacing a worker moves the epoch from one to two. The old worker's late result still carries one, so the controller rejects it. The check lives in the controller. That way, restoring a snapshot cannot revive an old permission. We also key each publish by its hash. Then a retry is a no-op, like a cache hit. Both are proposed. One controller, current epoch, publish once. What is still open?}
