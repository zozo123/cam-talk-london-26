\note{[1:00] The shared state is now a repository with an open issue. Brown and colleagues sampled patches from DeepSeek-Coder-V2-Instruct on SWE-bench Lite. With one sample, a correct patch appeared for 15.9 percent of tasks. With 250 samples, for 56 percent. That is coverage: at least one patch passes the hidden tests. In production there are no hidden tests. A selector must pick one patch from many wrong ones. Only that patch ships. Coverage is not selection. That is rule three, publish once.
