\begin{frame}{Coding RL turns reset into a training primitive}
\large
For coding RL, the environment is part of the training example.
\vspace{0.3em}
\begin{center}
\Large
$\text{episode}=\big(S_0,\;\text{task},\;\text{tools},\;\text{verifier},\;\text{reset}\big)$
\end{center}
\vspace{0.4em}
\begin{columns}[T,onlytextwidth]
\column{0.47\textwidth}
\textbf{Cold path}\par
\normalsize clone repo $\rightarrow$ install deps $\rightarrow$ build $\rightarrow$ run episode $\rightarrow$ throw away
\vspace{0.5em}
\warn{Reconstruct the same starting world again.}
\column{0.47\textwidth}
\textbf{Fork path}\par
\normalsize prepare once $\rightarrow$ snapshot $S_0$ $\rightarrow$ fork episode $\rightarrow$ burn child $\rightarrow$ fork again
\vspace{0.5em}
\ok{Reset becomes a runtime operation.}
\end{columns}
\source{SWE-smith: arXiv:2504.21798; Meta Code World Model (2025); public RL-environment products by Scale, Surge, Mercor, Prime Intellect.}
\end{frame}

\begin{frame}{Non-escape escapes}
\large
The agent does not need a kernel escape to defeat the experiment.
\vspace{0.5em}
\begin{tabular}{p{0.30\textwidth}p{0.55\textwidth}}
\toprule
\textbf{Failure} & \textbf{What goes wrong} \\
\midrule
Inherited credentials & The child gets authority that belonged to the parent. \\
Dangerous mounts & A writable path reaches the verifier, cache, or host. \\
Allowed egress & The child leaks secrets through a permitted endpoint. \\
Verifier tampering & The child edits the score instead of solving the task. \\
\bottomrule
\end{tabular}
\vspace{0.6em}
\begin{block}{Security lesson}
Sandboxing is not just a wall. It is a capability contract.
\end{block}
\end{frame}

\begin{frame}{What actually has to fork?}
\small
\begin{columns}[T,onlytextwidth]
\column{0.48\textwidth}
\begin{block}{Copy into the child}
\begin{itemize}
  \item filesystem + process / memory state
  \item pinned source, dependencies, toolchain
  \item enough state to continue the experiment
\end{itemize}
\end{block}
\begin{block}{Share carefully}
\begin{itemize}
  \item content-addressed build artifacts
  \item immutable heat / caches inside one trust domain
  \item CoW pages with explicit sharing policy
\end{itemize}
\end{block}
\column{0.48\textwidth}
\begin{block}{Remint at the boundary}
\begin{itemize}
  \item API / cloud credentials
  \item network capabilities and identity
  \item randomness / epoch identity when required
\end{itemize}
\end{block}
\begin{block}{Keep outside the child}
\begin{itemize}
  \item hidden verifier + objective digest
  \item promotion key / merge authority
  \item durable evidence ledger
\end{itemize}
\end{block}
\end{columns}
\vspace{0.3em}
\centering\Large \hilite{Copy the machine, not the keys.}
\end{frame}

\begin{frame}{Operating systems view: isolation layers}
\small
\begin{tabular}{p{0.22\textwidth}p{0.31\textwidth}p{0.35\textwidth}}
\toprule
\textbf{Layer} & \textbf{Good at} & \textbf{Caution} \\
\midrule
Process / namespace & Fast, ergonomic, cheap per task. & Shared kernel; boundary depends on configuration. \\
Container & Developer workflow, packaging, density. & Not automatically a strong isolation claim. \\
User-space kernel & Syscall mediation and compatibility tradeoffs. & Still must reason about devices, files, and egress. \\
MicroVM & Stronger guest boundary with useful density. & Boundary is not the whole experiment: credentials/oracle still matter. \\
\bottomrule
\end{tabular}
\vspace{0.6em}
\begin{block}{Systems point}
The isolation wall is necessary. The authority and evidence contracts are separate.
\end{block}
\end{frame}

\begin{frame}{Warmth is performance. Authority is a capability.}
\begin{columns}[T,onlytextwidth]
\column{0.47\textwidth}
\textbf{Safe warmth, if scoped}
\begin{itemize}
  \item immutable source snapshots
  \item compiler and dependency layers
  \item content-addressed artifacts
  \item cache hits with lineage
\end{itemize}
\column{0.47\textwidth}
\textbf{Dangerous warmth}
\begin{itemize}
  \item sibling-visible writable caches
  \item token/session material
  \item cross-tenant memory sharing
  \item hidden verifier residue
\end{itemize}
\end{columns}
\vspace{0.7em}
\begin{block}{Rule}
Pack by trust domain, not by utilization alone.
\end{block}
\end{frame}
