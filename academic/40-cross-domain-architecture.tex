\begin{frame}{What this is not}
\begin{itemize}
  \item Not a claim that all containers are bad.
  \item Not a claim that fork gives independent samples.
  \item Not a claim that learned world models are obsolete.
  \item Not a claim that every real-world service is captured by a snapshot.
  \item Not a claim that physics analogies prove thermodynamics of software.
\end{itemize}
\vspace{0.7em}
\begin{block}{What it is}
A capability contract for cheap executable search with separated evidence and authority.
\end{block}
\end{frame}

\begin{frame}{Research agenda for Cambridge SRG}
\large
\begin{enumerate}
  \item \term{Executable state}: what must a first-class machine value include - FS, memory, process tree, GPU, sockets, clock, external state?
  \item \term{Model vs world}: where is the crossover where learned imagination becomes cheaper than forked executable interaction?
  \item \term{Correlation}: how should reducers price shared ancestry instead of pretending siblings are i.i.d.?
  \item \term{Authority}: how do children inherit enough state to act without inheriting the power to grade or promote themselves?
  \item \term{Warmth}: where can caches live without becoming wires?
\end{enumerate}
\end{frame}

% 32
\begin{frame}{Takeaways}
\begin{enumerate}
  \item Software agents need \term{computers}, not just prompts.
  \item Coding RL needs \term{resettable executable environments}, not only datasets.
  \item World models make imagination cheap; forkable sandboxes make interaction cheap.
  \item Fork is only safe with reduce, evidence, and singular promote.
  \item The runner is disposable. The proof is durable.
\end{enumerate}
\vspace{0.8em}
\begin{center}
\Large \hilite{Burn the runner. Keep the proof. Fork the machine, not the trust.}
\end{center}
\end{frame}
